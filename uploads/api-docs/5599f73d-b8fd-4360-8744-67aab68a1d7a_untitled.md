# 🎉 Markdown.kr에 오신 것을 환영합니다!

**실시간 마크다운 에디터**로 문서를 쉽고 빠르게 작성해보세요.

## ✨ 주요 기능

### 📝 실시간 미리보기
- 왼쪽에 마크다운을 입력하면
- 오른쪽에 즉시 결과가 표시됩니다!

### 🛠️ 편리한 도구바
상단 도구바를 사용하면 마크다운 문법을 쉽게 입력할 수 있어요:

- **굵게** (*Ctrl+B*)
- *기울임* (*Ctrl+I*)
- [링크](https://markdown.kr)
- `인라인 코드`

### 💾 파일 관리
- **새 파일**: *Ctrl+N*
- **파일 열기**: *Ctrl+O* 
- **저장하기**: *Ctrl+S*
- **HTML 내보내기**
- **PDF 내보내기**

## 🎨 테마 & 화면
- 🌙 **다크모드** 지원
- 📱 **모바일** 최적화
- 🖥️ **전체화면** 모드 (F11)

## 📚 마크다운 문법 예제

### 제목 만들기
```
# 큰 제목
## 중간 제목  
### 작은 제목
```

### 목록 만들기
- 첫 번째 항목
- 두 번째 항목
  - 중첩된 항목
  - 또 다른 중첩 항목

1. 순서가 있는 목록
2. 두 번째 항목
3. 세 번째 항목

## 🚀 시작하기

1. **왼쪽 에디터**에서 이 텍스트를 지우고 자유롭게 작성해보세요
2. **오른쪽 미리보기**에서 실시간으로 결과를 확인하세요
3. **상단 도구바**를 클릭해서 다양한 문법을 시도해보세요
4. **[가이드 페이지](/guide.php)**에서 더 자세한 문법을 배워보세요
