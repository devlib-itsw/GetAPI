HATEOAS 설정

응답에 HAL(Hypertext Application Language) 형식의 HATEOAS 링크를 추가합니다. 활성화하면 API 응답에 관련 리소스 링크가 자동으로 포함됩니다.

HATEOAS가 활성화되면 원본 API 응답에 _links 객체가 추가되어 HAL 형식으로 반환됩니다.
