1. 서비스 소개

GetAPI는 개발자가 자신의 API를 등록·판매하고, 다른 개발자의 API를 포인트로 구매해 사용할 수 있는 API 마켓플레이스입니다.

API 제공자는 자신의 서버를 그대로 유지하면서 GetAPI 플랫폼에 연결하기만 하면 됩니다. API 사용자는 로컬에서 실행되는 경량 프록시 클라이언트를 통해 http://getapi/{slug} 형태의 URL로 인증 없이 API를 호출할 수 있습니다.

내 앱 → http://getapi/{slug} → getapi-proxy → 서명 자동 추가 → GetAPI 서버 → 원본 API 서버
역할주요 기능
API 판매자대시보드에서 API 등록 → Well-Known 검증 → 수익 확인
API 사용자라이브러리에서 API 탐색 → 포인트 충전 → 프록시 설치 후 호출

2. 로그인 · 프로필

GetAPI는 Google OAuth2 소셜 로그인만 지원합니다. 별도의 회원가입 절차 없이 구글 계정으로 즉시 시작할 수 있습니다.

  1. 우측 상단의 로그인 버튼을 클릭합니다.
  2. Google 계정을 선택하고 권한을 허용합니다.
  3. 첫 로그인 시 자동으로 계정이 생성됩니다.

전화번호 인증 (최초 1회)

처음 Google 로그인을 완료하면 전화번호 인증 페이지로 자동 이동됩니다. GetAPI는 전화번호 1개당 계정 1개만 허용하며, 인증은 최초 가입 시 1회만 진행됩니다.

1

전화번호 입력

인증 페이지에 본인의 휴대폰 번호를 입력합니다. 010-XXXX-XXXX 형식으로 입력하세요 (하이픈 생략 가능).

2

인증 문자 발송 요청

번호 입력 후 인증 문자 발송 버튼을 클릭합니다. 입력한 번호로 인증 코드가 포함된 문자가 발송됩니다.

3

SMS 답장으로 인증 완료

받은 문자 메시지에 표시된 코드를 그대로 답장(Reply)으로 전송합니다. 문자 내용을 수정하지 말고 그대로 보내야 합니다.

수정하지말고 그대로 전송해주세요. (XXXXXXXXXXXXXXXX)

답장을 보내면 페이지가 자동으로 인증 완료 상태로 전환되며 로그인이 완료됩니다.

인증 시 주의사항
  • 인증 코드는 10분 이내에 답장을 보내야 합니다.
  • 이미 다른 계정에 등록된 전화번호로는 가입할 수 없습니다.
  • 답장 문자 내용을 수정하면 인증에 실패합니다.

프로필 편집

마이페이지 → 프로필 편집 탭에서 아래 정보를 변경할 수 있습니다.

항목설명
프로필 사진Google 계정 아바타가 자동으로 사용되며 변경 불가입니다
닉네임사이트 내 표시 이름 (다른 사용자에게 공개)
자기소개공개 프로필 페이지에 표시되는 소개 문구
프로필 사진은 Google 계정에 등록된 이미지가 자동으로 적용됩니다. 사진을 변경하려면 Google 계정의 프로필 사진을 수정한 뒤 다시 로그인하세요.

공개 프로필

모든 사용자는 고유한 공개 프로필 페이지를 가집니다. URL은 /user/profile/{uuid} 형식이며, 다른 사용자가 직접 방문할 수 있습니다.

공개 프로필에는 다음 정보가 노출됩니다.

  • 닉네임 · 이메일 주소 · 프로필 사진 · 자기소개
  • 등록한 API 목록 (활성 상태인 것만 표시)
  • 작성한 커뮤니티 게시글
  • 가입일 · API 수 · 총 호출수 · 게시글 수

마이페이지

우측 상단 아바타 → 마이페이지에서 본인 계정의 전체 현황을 확인할 수 있습니다.

탭내용
프로필 편집닉네임, 자기소개 변경
포인트잔액 확인, 충전·환전 이동
API 키 관리Secret Key 발급, API Key 재발급, 만료일 확인

회원 탈퇴

마이페이지 하단 회원 탈퇴 버튼을 통해 탈퇴할 수 있습니다.

탈퇴 시 계정은 즉시 비활성화되며 데이터는 90일간 보관 후 완전 삭제됩니다. 탈퇴 후에는 동일 Google 계정으로 재가입이 가능합니다.

3. 포인트 시스템

GetAPI는 포인트(P) 기반으로 API 호출 비용을 결제합니다. API를 호출할 때마다 해당 API에 설정된 포인트가 차감되며, 판매자에게 수익으로 누적됩니다.

포인트 충전

상단 네비게이션 → 포인트 메뉴 또는 충전 페이지에서 토스페이먼츠로 결제합니다.

  1. 충전 금액을 선택하거나 직접 입력합니다.
  2. 결제 수단(카드, 간편결제 등)을 선택합니다.
  3. 결제 완료 후 포인트가 즉시 잔액에 추가됩니다.

포인트 환전

환전 페이지에서 누적된 수익 포인트를 현금으로 환전할 수 있습니다. 환전은 관리자 승인 후 처리됩니다.

포인트가 부족한 상태에서 API를 호출하면 402 Payment Required 오류가 반환됩니다. 호출 전 잔액을 확인하세요.

4. API 라이브러리

등록된 모든 API를 탐색하고, 원하는 API의 문서를 확인하거나 즐겨찾기할 수 있습니다.

탐색 · 검색 · 정렬

  • 상단 검색창에 키워드를 입력하고 Enter를 누르면 API 이름·설명으로 검색됩니다.
  • 태그 버튼으로 카테고리를 필터링하거나, 정렬 드롭다운으로 최신순 / 인기순 / 호출수순을 변경할 수 있습니다.
  • API 카드를 클릭하면 상세 페이지로 이동합니다.

서버 상태 표시

API 상세 페이지의 API 이름 옆에 작은 원형 상태 표시등이 있습니다. 페이지 진입 시 원본 서버에 자동으로 헬스 체크를 수행하며, 결과에 따라 색상이 바뀝니다.

색상의미
회색확인 중 (페이지 로딩 직후)
초록서버 정상 응답
빨강서버 응답 없음 또는 오류

상태가 빨강이어도 API 등록 자체가 삭제되는 것은 아닙니다. 원본 서버가 일시적으로 다운됐거나 방화벽으로 외부 헬스 체크를 막고 있을 수 있습니다.

즐겨찾기(Star)

API 상세 페이지 우측 상단의 ★ Star 버튼을 클릭하면 즐겨찾기에 추가됩니다. 다시 클릭하면 해제됩니다. 마이페이지에서 즐겨찾기 목록을 확인할 수 있습니다.

댓글

API 상세 페이지 하단에서 사용 후기나 질문을 댓글로 남길 수 있습니다. 자신이 작성한 댓글은 수정·삭제할 수 있습니다.

5. API 사용하기 (getapi-proxy)

GetAPI의 API를 호출하려면 로컬에서 실행하는 경량 프록시 클라이언트(getapi-proxy)가 필요합니다. 프록시가 인증 헤더를 자동으로 처리하므로, 내 앱 코드에는 인증 로직이 전혀 필요하지 않습니다.

① Secret Key 발급

프록시 실행에 앞서 Secret Key를 먼저 발급받아야 합니다. Secret Key는 HMAC-SHA256 서명에 사용되며 한 번만 발급됩니다.

  1. 마이페이지 → API 키 관리 탭으로 이동합니다.
  2. Secret Key 발급 버튼을 클릭합니다.
  3. 표시되는 키를 안전한 곳에 복사해두세요. 이후에는 다시 확인할 수 없습니다.
Secret Key를 분실하면 재발급이 필요합니다. 재발급 시 기존 키로 실행 중인 프록시는 더 이상 인증되지 않으니 주의하세요.

② getapi-proxy 설치

OS에 맞는 바이너리를 다운로드 페이지에서 받거나, 아래 터미널 명령어로 바로 내려받을 수 있습니다.

Linux (amd64)

Linux (arm64)

macOS (Apple Silicon)

macOS (Intel)

Windows (PowerShell — 관리자로 실행)

소스 직접 빌드

git clone https://github.com/devlib-itsw/getapi-client.git cd getapi-client go build -o getapi-proxy ./proxy.go

③ 실행 및 Device Flow 인증

프록시는 포트 80을 사용하므로 관리자(root) 권한이 필요합니다.

Linux / macOS

sudo ./getapi-proxy

Windows

.\getapi-proxy.exe # 관리자 권한으로 실행

실행하면 다음 순서로 초기 설정이 진행됩니다.

1

로깅 여부 선택

로그를 파일로 저장할지 선택합니다. y를 입력하면 로그 경로를 지정할 수 있으며, 기본값은 .getapi-log/입니다.

로깅 사용? (y/n): y 로그 경로 (엔터: .getapi-log/): [엔터] [✓] 로그 파일: .getapi-log/2026-04-25.log
2

Device Flow 인증 (RFC 8628)

브라우저가 자동으로 열리며 인증 코드가 클립보드에 복사됩니다.

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━ Visit: http://getapi.lol/auth/device/activate Code: ABCD-1234 (클립보드에 복사됨) 유효시간: 600초 ━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

브라우저에서 GetAPI에 로그인한 뒤, 표시된 8자리 코드를 입력하고 승인하면 인증이 완료됩니다.

3

프록시 시작

인증 완료 후 /etc/hosts에 getapi 도메인이 자동 등록되며 프록시가 포트 80에서 실행됩니다.

[✓] 인증 완료. 만료일: 2026-05-02 Running on http://getapi:80
프록시를 종료하면(Ctrl+C) /etc/hosts 항목이 자동으로 삭제됩니다. API Key와 Secret Key는 메모리에만 보관되며 파일에 저장되지 않습니다.

④ API 호출

프록시 실행 후 기존 호출 URL 대신 http://getapi/{slug}로 요청합니다. 인증 헤더는 프록시가 자동으로 추가합니다.

# GET 요청 curl http://getapi/weather-api/v1/current?city=Seoul # POST 요청 curl -X POST http://getapi/my-api/v1/analyze \ -H "Content-Type: application/json" \ -d '{"text": "Hello World"}'
자동으로 추가되는 헤더설명
X-GetAPI-Key발급된 API Key
X-GetAPI-TimestampUTC ISO 8601 타임스탬프
X-GetAPI-SignatureHMAC-SHA256 서명 (body + timestamp)

API Key는 7일마다 자동 갱신됩니다. 갱신은 자정에 백그라운드에서 처리되므로 별도 작업이 필요 없습니다.

⑤ 보안 구조

항목내용
서명 알고리즘HMAC-SHA256 (body + timestamp)
타임스탬프 유효 범위±5분 (Replay Attack 방지)
API Key 유효 기간7일 (Rotation Token으로 자동 갱신)
키 저장 방식메모리에만 보관 (파일 저장 없음)
hosts 자동 정리프록시 종료 시 /etc/hosts 항목 자동 삭제

6. API 판매하기

본인이 운영하는 API 서버를 GetAPI 플랫폼에 연결하면, 다른 개발자들이 포인트로 API를 사용하고 수익이 누적됩니다.

① API 등록

대시보드 → 새 API 등록 버튼을 클릭합니다.

필드설명예시
API 이름라이브러리에 표시될 이름날씨 API
HTTP 메서드원본 API의 기본 메서드GET
URL Slug프록시 경로 식별자 (비워두면 자동생성)weather-api
원본 API URL실제 API 서버의 엔드포인트https://api.example.com/weather
설명API 기능 설명 (라이브러리 표시)실시간 날씨 데이터 제공
API 문서Markdown 형식의 .md 파일README.md
태그콤마(,)로 구분해서 입력날씨, 기상청, open-data
호출당 포인트1회 호출 시 차감될 포인트10
URL Slug는 http://getapi/{slug}의 경로 부분입니다. 영문·숫자·하이픈을 권장하며, 한 번 등록하면 신중하게 변경하세요.

② Well-Known 소유권 검증

API 등록 후 원본 서버의 소유권을 검증해야 합니다. GetAPI가 생성한 토큰을 원본 서버의 특정 경로에 노출시키는 방식입니다.

1

검증 토큰 확인

등록 완료 후 검증 페이지에서 토큰을 확인합니다.

토큰 예시: getapi_verify_a3f8d29c...
2

원본 서버에 Well-Known 경로 추가

원본 API 서버의 루트 도메인 기준으로 다음 경로에서 토큰 문자열만 반환하도록 설정합니다.

GET https://api.example.com/.well-known/getapi-verify → 응답 본문: getapi_verify_a3f8d29c...

Spring Boot 예시

@GetMapping("/.well-known/getapi-verify") @ResponseBody public String verify() { return "getapi_verify_a3f8d29c..."; }

Express (Node.js) 예시

app.get('/.well-known/getapi-verify', (req, res) => { res.send('getapi_verify_a3f8d29c...'); });

Nginx 정적 파일 예시

location /.well-known/getapi-verify { return 200 'getapi_verify_a3f8d29c...'; add_header Content-Type text/plain; }
3

검증 요청

검증 페이지에서 검증하기 버튼을 클릭합니다. GetAPI 서버가 원본 서버의 well-known 경로를 호출해 토큰을 비교합니다. 일치하면 API가 즉시 활성화됩니다.

검증 토큰은 등록 후 10분간만 유효합니다. 시간 내에 검증을 완료하지 못하면 API를 다시 등록해야 합니다.

③ API 관리

대시보드 → API 카드를 클릭하면 상세 관리 페이지로 이동합니다.

  • 통계: 총 호출수, 오늘 호출수, 총 수익, 최근 호출 로그 50건
  • 정보 수정: 이름, 설명, 가격, URL Slug 변경 가능
  • 문서 업데이트: 새 .md 파일을 업로드하면 즉시 반영됩니다
  • 삭제: API를 영구 삭제합니다. 복구할 수 없습니다

④ HATEOAS 설정 (선택)

원본 API가 JSON을 반환하는 경우, GetAPI 프록시가 응답에 _links 필드를 자동으로 주입할 수 있습니다.

  1. API 관리 페이지 → HATEOAS 탭으로 이동합니다.
  2. 토글로 활성화 후, rel(관계명), URI, Method를 입력해 링크를 추가합니다.
  3. 저장하면 이후 API 응답에 자동으로 주입됩니다.
// 응답 예시 (_links 자동 주입) { "id": 1, "name": "Seoul", "temp": 22.5, "_links": { "forecast": { "href": "/weather/forecast", "method": "GET" }, "history": { "href": "/weather/history", "method": "GET" } } }
HATEOAS 활성화는 원본 API가 application/json을 반환해야 합니다. JSON이 아닌 응답에는 주입되지 않습니다.

7. 커뮤니티

커뮤니티에서 API 홍보, 제작 외주 요청, 개발 관련 정보를 공유하세요.

  • 글 작성: 제목, 내용, 태그를 입력해 게시글을 등록합니다. 마크다운을 지원합니다.
  • 좋아요: 게시글 하단의 좋아요 버튼으로 좋아요를 추가하거나 취소합니다.
  • 댓글: 게시글에 댓글을 달고, 자신의 댓글은 수정·삭제할 수 있습니다.
  • 검색 · 정렬: 키워드 검색, 태그 필터링, 최신순/인기순 정렬이 가능합니다.
커뮤니티 게시글과 API는 AI 자동 검열 시스템을 통해 부적절한 내용이 필터링됩니다. 문제가 없는 경우에도 일시적으로 검토 중 상태가 될 수 있습니다.
