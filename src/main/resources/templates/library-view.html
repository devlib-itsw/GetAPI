API 사용법

Endpoint

POST https://getapi.com/api/tr-abc123/translate

Headers

Authorization: Bearer YOUR_API_KEY

Content-Type: application/json

Parameters

Name Type Required Description
text string Yes 번역할 텍스트
source string No 원본 언어 코드 (자동 감지)
target string Yes 번역 대상 언어 코드

Code Example

// JavaScript Example
const response = await fetch('https://getapi.com/api/tr-abc123/translate', {
  method: 'POST',
  headers: {
    'Authorization': 'Bearer YOUR_API_KEY',
    'Content-Type': 'application/json'
  },
  body: JSON.stringify({
    text: '안녕하세요, 반갑습니다.',
    source: 'ko',
    target: 'en'
  })
});

const data = await response.json();
console.log(data.translated); // "Hello, nice to meet you."
