Translation API

100개 이상의 언어를 지원하는 고품질 번역 API입니다. 자연스러운 번역과 빠른 응답 속도를 제공합니다. 딥러닝 기반의 신경망 번역 모델을 사용하여 문맥을 파악한 자연스러운 번역 결과를 제공합니다.

번역 다국어 NLP AI 텍스트

API 사용법

Endpoint

POST https://getapi.com/api/tr-abc123/translate

Headers

Authorization: Bearer YOUR_API_KEY

Content-Type: application/json

Parameters

Name Type Required Description
text string Yes 번역할 텍스트
source string No 원본 언어 코드 (자동 감지)
target string Yes 번역 대상 언어 코드

Code Example

// JavaScript Example
const response = await fetch('https://getapi.com/api/tr-abc123/translate', {
  method: 'POST',
  headers: {
    'Authorization': 'Bearer YOUR_API_KEY',
    'Content-Type': 'application/json'
  },
  body: JSON.stringify({
    text: '안녕하세요, 반갑습니다.',
    source: 'ko',
    target: 'en'
  })
});

const data = await response.json();
console.log(data.translated); // "Hello, nice to meet you."
